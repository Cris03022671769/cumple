# cumple

Página estática para felicitar a Gloria con las imágenes del proyecto y un contador hacia su cumpleaños.

## Publicarla en GitHub Pages

1. Sube el contenido del repositorio a GitHub.
2. Entra en `Settings` > `Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona la rama principal y la carpeta raíz.
5. Guarda los cambios y espera a que GitHub genere la URL pública.
